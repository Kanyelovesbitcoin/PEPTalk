# GlowPep App Store Submission Package

## Positioning

GlowPep is a private peptide education and tracking app. It helps users browse educational Library entries, create user-entered routine trackers, move through Today's Rotation, keep local logs and personal notes, use calculators, and export their record.

GlowPep is not a medical app, prescriber, diagnostic tool, treatment planner, dosing recommender, pharmacy, marketplace, or sourcing guide.

## Short App Review Description

GlowPep is a private education and tracking app for adults who want to keep peptide-related research notes in one place. Users can browse an educational Library, create personal log entries, set discreet reminders, and organize their own Today's Rotation from tracker details they enter themselves. GlowPep does not diagnose, treat, prescribe, recommend products, recommend amounts, sell products, or replace a licensed clinician.

Free users can browse the Library, use Today's Rotation, keep local logs, and save personal notes. Pro users can start a trial for the deep questionnaire, AI-assisted educational organization, exports, multiple saved shortlists, and private reminders. AI features disclose when data is sent to the hosted API.

## Subscription Description

GlowPep Pro is an auto-renewable subscription that unlocks ongoing digital functionality: deep questionnaire, AI-assisted organization, exports, multiple saved shortlists, full compound depth, and private reminders.

## Permission Narrative

GlowPep does not request camera or photo library access.

Notification permission is requested only when a user explicitly enables a private routine reminder. Reminder notifications are intentionally discreet and do not include compound names or amounts.

## Privacy Summary

- User content: Library choices, user-entered schedules, amount logs, check-ins, notes, questionnaire answers, and saved shortlists are stored on device.
- AI: Guide answers and selected context are sent only when the user requests AI-assisted educational organization.
- Purchases: Subscription status is handled through RevenueCat and Apple purchase flows.

## Reviewer Demo Flow

1. Complete rotation-led onboarding.
2. Dismiss the paywall to inspect the free path: Today, Library, Today's Rotation, local tracker, and Profile privacy controls.
3. Add a Library item to the tracker with a user-entered amount and schedule.
4. Use Today's Rotation to log, skip, and undo a scheduled item.
5. Start trial or use the sandbox purchase flow to inspect Pro: deep questionnaire, saved shortlist, exports, and reminders.
